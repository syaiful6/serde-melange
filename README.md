# serde-melange

This is basically a copy and reiteration of [serde.ml](https://github.com/serde-ml/serde) so
I can use it in Melange projects.

This project includes JSON serialization and deserialization, the implementation uses javascript's
`JSON.parse` and `JSON.stringify` under the hood.

I will try to keep the API as close to serde-ml as possible, so we can reuse code for native
and frontend (melange).

For now you can look at the examples directory and read our test cases how to use it.
